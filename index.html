🚀 HOW TO START | ESSENTIAL COMMANDS

Step 1: Update & Upgrade (First Command Ever)
sudo apt update && sudo apt upgrade -y (Kali Linux / Ubuntu)
pkg update && pkg upgrade (Termux - Android)
apk update && apk upgrade (iSH - iOS)
Step 2: Install Essential Tools
sudo apt install git python3 nmap wireshark gobuster dirb -y
pip3 install requests scapy beautifulsoup4
git clone https://github.com/LK-HACKERS/LK-HACKERS.git
Step 3: Setup Anonymity (VPN + ProxyChains)
sudo apt install proxychains4 tor -y
sudo systemctl start tor
proxychains nmap -sT target.com
Step 4: Start CTF Platforms (For Beginners)
➜ TryHackMe: https://tryhackme.com/ - Start with "Pre Security" path
➜ OverTheWire Bandit: ssh bandit0@bandit.labs.overthewire.org -p 2220
➜ Hack The Box: Create account → Starting Point machines
